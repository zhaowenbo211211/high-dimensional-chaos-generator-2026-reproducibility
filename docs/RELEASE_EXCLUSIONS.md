# Public candidate exclusions and pending permissions

Excluded: complete papers/reference PDFs; raw Cooja images, image headers and image-bearing packet data (provenance/rights unconfirmed); original FPGA generated RTL, netlists, placement/routing, DCP/bitstreams, vendor IP/tool installations and Vivado caches; original STS executables/runtime; credentials, private device identities and virtual environments. Existing scientific numerical data and selected sanitized evidence are not freshly recomputed. `data/figures/scientific_publication_b2/figure2_le.pdf` is one stored numerical panel needed by the existing data-only adapter; it is not vendor FPGA output.

The author-selected `software/prng371/golden_371.so` and an identical path-compatible copy are the sole permitted precompiled backend exceptions; both are Linux x86-64 and their distribution rights need confirmation. All other source code, copied third-party baseline/metric functions, numerical data, historical reports and Cooja source remain pending author/third-party rights and license review. No public release is authorized. No `LICENSE` file is created until the author chooses a license.

The repository is not a full FPGA project: exact paper netlist rebuilding is not claimed. Full original trajectories and exact Cooja image reconstruction remain unavailable.
