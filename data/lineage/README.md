# Data lineage

`paper_objects.json` is the earlier R2 label inventory and source-pointer evidence; `data/figures/README.md` and `data/tables/README.md` are the current candidate's mapping. Aliased R2 source paths are archival locators, not paths guaranteed to exist in this candidate. `experiment_configs/`, `nist/`, `cooja/` and `derived_diagnostics/` preserve selected existing records. The 865 task summaries live under `data/experiments_rev1_alignment/results/cache/`; they are not raw trajectories. The archived `run_status.json` also describes retired A tasks and is not a new run.
