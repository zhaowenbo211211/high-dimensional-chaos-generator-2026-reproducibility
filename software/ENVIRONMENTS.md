# Environment provenance

Local candidate only; NOT PUBLIC APPROVED. Runtime bounds in the new requirements files are dependency declarations, not a lock or a claim of historical environment reconstruction. No dependencies were installed during packaging.

The historical experiment listing is preserved verbatim at `experiments_rev1_alignment/provenance/requirements_rev1.txt`. It lists Python 3.12.11, NumPy 2.2.3, Matplotlib 3.10.9, matplotlib-inline 0.1.6, PyYAML 6.0.1, ruamel.yaml 0.19.1, SciPy 1.14.1 and types-PyYAML 6.0. It is a whitespace package inventory including a Python line; do not pass it to pip as requirements. The separate copied lower bounds remain historical provenance at `requirements_copied.txt`. Current scientific plotting also imports PyMuPDF (`fitz`), whose historical version was not recorded. Font settings use STIXGeneral and STIX mathtext; exact PDF bytes can depend on runtime/fonts.

The supplied generic project pyproject is byte-exact and declares Python >=3.8 and NumPy >=1.20, with Matplotlib optional. Its unchanged top-level `chaos` initializer eagerly imports Matplotlib-based analysis/visualization, so use `pip install './software/hd_chaos_project[viz]'` or install the candidate runtime requirements before importing `chaos`. The candidate-wide Python >=3.10 guidance also covers current experiment syntax and zip(strict=True) in the bars renderer; it does not rewrite the generic project's metadata.

The generic project's original desktop/OS requirements inventory is excluded. Its SHA-256 is recorded in COPY_LOG.json; its NumPy 2.2.3 and PyYAML 6.0.1 entries are historical inventory observations, not proof of a portable environment. The retained legacy comparison entrypoints import PyYAML via utils/io_utils.py, which is why candidate full requirements include PyYAML. The data-only route requires no PyYAML. Existing semantic tests are retained; running the entire original test script includes a Wolf diagnostic and is beyond the packaging checks performed here.
