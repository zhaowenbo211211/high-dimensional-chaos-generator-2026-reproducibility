# metrics

This folder contains metric implementations and post-processing helpers.

Main categories:

- chaotic-performance metrics such as `LE`, `SE`, `FE`, `PE`, and `SI`
- NIST-facing bitstream preparation helpers
- system-level PRNG post-processing logic
- lightweight mixing, truncation, and whitening utilities

Use this folder when you need the mathematical evaluation logic itself rather
than a runnable experiment wrapper.
