# Current experiment implementation

Local candidate only; NOT PUBLIC APPROVED. This is the current paper's 16-bit Mode II numerical implementation. Source, original task builders, runners, aggregation/export scripts, configurations, semantic tests and publication plotting helpers are byte-exact copies. R1-LY in source identifiers is the historical name of the current paper's R1-CS parameter synthesis; see `../../docs/SOFTWARE.md` for the crosswalk and limits.

Frozen results are kept separately at `../../data/experiments_rev1_alignment/results`. Run `python software/stored_data.py validate` from the candidate root to check retained CSV hashes, counts and archived task records without recomputing a scientific metric. Run `python software/stored_data.py replot --output-dir /tmp/paper2025-replot` to render the frozen publication panels in temporary staging and put outputs in that new directory. The latter uses the original B2 renderer followed by the later bars renderer. Both the selected-array dictionaries and six CSV hashes are checked. Original path-dependent scripts are retained for provenance; use the wrapper for portable stored-data plotting.

The unchanged `scripts/run_all.py` includes historical experiment A in its default task set. Its presence preserves the source API; A dynamical results are retired and are excluded from current candidate data. Numerical runners and tests are opt-in and were not run as a full reproduction here. They write `results` relative to this software subtree, not into the separated frozen data archive. Use an isolated copy and choose the intended B/D/E task scope explicitly for future numerical work. The original `replot_original_style.py` includes a deployment step into the neighboring paper figures tree; it is not the supported wrapper route.

B defines 119 odd A groups (271..507); D covers n=4..12; E covers five methods across n=4..12. Configs/recommended_parameters.csv describes experiment A=371 and is not the paper's analytical A=271 recommended table. Stored data are not complete trajectories. Historical reports under provenance/historical_audit are historical observations, not fresh packaging test results.
