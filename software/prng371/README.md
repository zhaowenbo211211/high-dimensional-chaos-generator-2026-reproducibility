# PRNG-371 software reference

`golden_prng.py` is the author-identified wrapper with a maintainer comment added; the adjacent `golden_371.so` is byte-identical to the source binary. The same files in `../hd_chaos_project/hw/src_371/` have identical SHA-256 hashes. See `../SOURCE_MANIFEST.json` for the individual source paths and digests.

The shared library is a precompiled Linux x86-64 binary; its C source has not been recovered, so rebuilding it is not supported. It was not loaded or executed in preparing this candidate. Distribution rights are pending confirmation; no license is assigned here.
